01 — About

I build software that stays fast under real traffic.

I’m a software engineer with a backend core. At Amdocs, I build and evolve Java microservices for CatalogONE, a multi-tenant telecom BSS platform — with clear APIs, resilient error handling, and container-friendly deployments.

My work is measured in production: profiling services to make APIs roughly 15% faster, tightening Hibernate queries for ~20% lower database execution time, and backing every change with JUnit tests and code review. I care about the unglamorous parts — validation, transactions, indexes, and error paths — because that is what keeps a system dependable.

Beyond that, I build full-stack projects and live client websites — designing schemas, writing APIs, and creating responsive interfaces. My latest, DSP Power Infra, is a live solar EPC site with a savings calculator, subsidy guidance, and a consultation flow — built and deployed end to end.
